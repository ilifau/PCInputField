INSTALLATION
------------

1. Put the content of the plugin directory in a subdirectory under your ILIAS main directory:
Customizing/global/plugins/Services/COPage/PageComponent/PCInputField

2. Open ILIAS > Administration > Plugins

3. Update/Activate the Plugin.


USE
---

The PCInputField allows you to send an input to a submission within ILIAS via an input field within a page element.
